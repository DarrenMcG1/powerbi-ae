# powerbi-ae

A Power BI report on Scotland's A&E waiting times, built by hand to
learn Power Query, a star schema and DAX. A learning repository, not a
product: every measure is the owner's own, written without coding
agents, so that it survives an interview walkthrough.

- **What is due and when:** [`docs/spec.md`](docs/spec.md), three
  afternoons a week from 2026-10-19 to 2026-11-04.
- **The report:** `report/`, saved as a Power BI project so its M and
  DAX are text in git, with a PDF export.

The owner's write-up replaces this file at the last step.

## Data

Contains public sector information licensed under the Open Government
Licence v3.0. Source: Public Health Scotland,
[Monthly A&E Activity and Waiting Times](https://www.opendata.nhs.scot/dataset/monthly-accident-and-emergency-activity-and-waiting-times),
[Hospital Codes](https://www.opendata.nhs.scot/dataset/hospital-codes)
and
[Geography Codes and Labels](https://www.opendata.nhs.scot/dataset/geography-codes-and-labels).
